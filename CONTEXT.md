# Контекст домена

## Термины

- **Messenger source** — платформа, через которую пользователь отправил сообщение; в этой системе допустимы `telegram` и `max`.
- **External user ID** — идентификатор пользователя, выданный конкретным messenger source; одинаковое числовое значение на разных платформах означает разных внешних пользователей.
- **External chat ID** — идентификатор чата в конкретной платформе.
- **External message ID** — идентификатор сообщения в конкретной платформе; он может быть числом или строкой.
- **Incoming image** — изображение, полученное от пользователя вместе с источником и внешними идентификаторами, подготовленное для общей OCR-обработки.
- **Passport record** — сохранённый результат распознавания паспорта и его качество, связанный с messenger source и внешним контекстом сообщения.
